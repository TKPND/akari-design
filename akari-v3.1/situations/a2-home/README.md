## 次の生成で使う役割

A-2はミルクティー色の細チェックのジャンパースカート、クリーム色の丸襟長袖、
ココア色のリボン、アイボリーの膝下丈靴下を引き継ぐ私服の参照。
前の包みボタンは3個。画角や腕で隠れる部分は無理に見せない。
この衣装の色指定は室内のA-2シーン用で、基本セットのグレー靴下を変更しない。

顔・目・黒髪ボブ・描き方はP1、普段の閉じ口の微笑みはP2。
原寸U1は上半身とシルバー細ピンの細部、原寸L1は脚と靴下の構造を担当する。
新しい場面ではP1・P2・U1・L1に、採用画像1枚を衣装・雰囲気の補助として加える。
採用画像の顔を新しい原本にはしない。構図・ポーズ・カメラは自由に変える。
見える靴下はF09の丸く不透明なつま先と浅くまばらな自然なしわを必須とする。
修正時は対象画像を構図・ポーズ・カメラの唯一の基準にする。

## 修正と保存

N10は前ボタンを3個に揃えたr2、N15は靴下の質感を調整したr1を採用。
N08・N12は初回出力を採用した。N12では靴下は画面外。
画像は生成出力のバイトをそのまま保存し、プロンプト・入力順・役割・修正前画像・
拡大確認画像を来歴と一緒に残している。
衣装の元のA案など、生成に必要だった祖先画像は来歴のみとして保存した。
未選択の12枚のR/S候補は採用に含めていない。

[採用記録](selection.json)、[画像・生成記録一覧](manifest.json)、
[保存検証](validation.json)を参照。
JSON内の実ファイル参照はすべて `akari-v3.1/` 基準。
`source_copy_map` の値は元の作業場所を記録した履歴で、再利用時には不要。
生成ツールの実モデルIDは不明。

保存検証は `python3 akari-v3.1/situations/a2-home/verify.py` で再実行できる。
