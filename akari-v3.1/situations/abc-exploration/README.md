## 制服と参照の役割

今回の制服はユーザー指定の[V31-06](references/V31-06.png)です。
長袖の濃紺ボレロ、白い丸襟ブラウス、濃紺リボン、
青灰色の細かなチェック柄プリーツスカートを引き継いでいます。
室内はグレーの膝下リブ靴下を残し、白スニーカーは玄関の土間に置きます。

- P1：顔・目・黒髪ボブ・描画の原本。
- P2：普段の閉じ口の微笑みの原本。
- U1：上半身・目元・髪・シルバー細ピンの細部。
- L1：下半身・脚・グレー靴下・白スニーカーの細部。
- V31-06：今回の制服と鞄。顔の基準にはしません。
- S1：ピンの形・位置の確認。5画像の入力上限により別入力には含めていません。

[参照記録](references.json)に参照先・役割・SHA-256があります。
生成時はP1/P2と原寸U1/L1、V31-06を個別の入力として渡しました。
A04の修正は対象画像を先頭にし、P1/P2/U1/L1を補助入力として渡しています。
修正対象に描かれた今回の制服・場面・カメラを優先しました。

この制服指定と場面の採用は本パッケージの範囲です。
既存の[参照セット](../../reference-set.json)と顔の基準は変更していません。

## A04の修正

元画像は右足を左の靴へ入れようとしているように見えました。
これは意図的なボケではなく、初回の目視選別で見落とした生成ミスです。

修正版は、元の「靴を脱ぎかけ」から「脱ぎ終えて上がる瞬間」へ少し進めています。
左足全体は木床の上、右足は土間と靴から離れた空中にあり、
空の白スニーカー2足は土間に残っています。
全体と足元の拡大画像で確認しました。

- [採用修正版 A04-r4](images/A04-r4.png)
- [元画像](history/A04-original.png)
- [修正履歴・入力・評価](history/A04-correction.json)

ユーザーが選択したのは18場面です。A04-r4はその選択と不具合指摘を受けて修正し、
助手が確認したもので、修正版単体への追加承認とは区別して記録しています。
修正に実際に使った元画像と中間2枚、各プロンプトも`history/`へ保存しました。
