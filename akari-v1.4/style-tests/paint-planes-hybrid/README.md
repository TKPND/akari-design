# Akari v1.4 — D: Paint-Plane Hybrid Test

## Inputs

- Edit target: `../paint-planes/akari-v14-c1-soft-planes.png`
- Direction reference: `../paint-planes/akari-v14-c3-strong-planes.png`

C1 remains the practical base. C3 is used only as a reference for larger,
cleaner light/midtone/shadow masses.

## Fixed invariants

- Character identity, age impression, expression, pose, and framing
- B1 face rendering and A2 eye highlights
- A3 line-pressure variation, selective broken lines, and sparse redraw lines
- Hair silhouette, locks, flyaways, crossed pins, and bow
- Garment cut, seams, fold geometry, and drawstring
- Skin, hands, background, bedding, curtain, and directional sunlight
- No grain, paper texture, bloom, chromatic aberration, or added objects

## Variants

| Variant | Permitted paint-plane change | File |

The variants were independently edited from C1. None was generated from
another D variant.

## Comparison

`akari-v14-d-hybrid-comparison.png` shows C1, D1, D2, and D3 at full-frame
scale and with the same upper-body crop.

## User selection

**D2 is formally accepted** as the v1.4 hair-and-clothing paint-plane base.
D3 remains a direction reference only.
