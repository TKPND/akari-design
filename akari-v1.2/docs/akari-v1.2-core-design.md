# あかり v1.2 Core 設計書

**Version:** v1.2.0<br>
**Codename:** Natural Form<br>
**Status:** Natural Form Core Release
**Date:** 2026-07-13

The v1.2.0 PDF and SHA-256 checksum are published under `release/`.

---

## 0. 文書の目的

本書は、あかり v1.2 Core の制作判断、生成、レビュー、採否、版管理、リリース運用を一貫させるための正式設計書である。

v1.2 は別キャラクターへの変更ではない。v1.1 で確立した identity lock を継承し、日常動作における姿勢、重心、脱力、生活状態を追加定義する。

### 設計テーマ

**自然体**

### 設計命題

> v1.1 が「立ち絵として正しいあかり」なら、<br>
> v1.2 は「生活している途中でも正しいあかり」。

# 第1章：目的・非目的・成功条件

## 1. バージョンの位置づけ

あかり v1.2 は、v1.1 のキャラクターデザインを置き換えるものではない。

以下の identity lock を継承する。

- 短い暖色ブラウンのボブ
- キャラクター左側の平行ピンと小リボン
- 丸みのある顔
- 暖色ブラウンの瞳
- コンパクトなアニメ等身
- 健康的でしっかりした脚
- 白・グレー・淡いブルーを中心とした配色
- 白系トップス、グレーのプリーツスカート
- 白い二本ライン入り靴下
- 白いチャンキースニーカー
- 柔らかく淡い人物描写

v1.1 で定義済みの配色、体型、正面・背面・45度、表情、靴、靴下、バッグは原則として維持する。v1.2 では、それらに姿勢・重心・脱力・生活状態のレイヤーを追加する。

## 2. 改善対象

### 第一優先：脚と重心

- 骨盤、膝、足首が一続きに見える
- 左右の脚に不自然なねじれがない
- 床座りで脚が身体から自然につながる
- 足先が硬く伸びすぎない
- 健康的な脚のボリュームを維持する
- 可愛さのために無理な関節角度を使わない

### 第二優先：脱力した姿勢

- 肩を上げすぎない
- 背筋を常に伸ばし切らない
- 座った時に骨盤が自然に傾く
- 上半身と下半身が同じ重心に従う
- 左右対称すぎるポーズを避ける

### 第三優先：朝の生活状態

- 起床直後の軽い寝癖
- まだ焦点の合い切らない視線
- 眠さによるまぶた、眉、口元の変化
- 室内で靴を脱いだ靴下姿
- 白Tシャツと短パン系部屋着
- ベッド脇やラグ上の生活空間

### 第四優先：日常微表情

v1.1 の Neutral と Soft Smile の間を細分化する。

1. 起床直後のぼんやり
2. 眠いまま安心している
3. 口元がわずかに緩む
4. 柔らかく笑う

## 3. 非目的

v1.2 Core では以下を行わない。

- 顔立ちの大幅な変更
- 頭身の変更
- 脚を細くする調整
- 新しい基本衣装の導入
- 髪型そのものの変更
- 髪飾りの位置変更
- スニーカーやバッグの再設計
- 手の詳細な設定資料
- 小物を持つポーズの体系化
- 夜、帰宅後、雨、屋外などの広範なシーン展開
- 背景表現を人物より優先すること

手、小物、新規衣装は身体基準が安定した後の Daily フェーズで扱う。

## 4. 成功条件

### Identity

- 顔だけ見ても v1.1 のあかりと認識できる
- 髪型と髪飾り側が維持されている
- D65 基準から大きな色漂流がない
- 年齢感とキャラクターの雰囲気が変わっていない

### Body

- 正面、背面、左右45度で体型が一致する
- 床座りで骨盤、膝、足首の接続が自然
- 脚の太さが角度によって大きく変わらない
- 左右の足が同じ身体構造に見える
- 頭身が無意識に高くなっていない

### Humanization

- 座り姿が記号的なポーズに見えない
- 身体のどこに体重が乗っているか分かる
- 肩、背中、足先に脱力が見える
- 寝癖が別髪型ではなく生活変化として読める
- 眠い顔が単なる目の縮小になっていない

### Daily 適性

- 朝の室内シーンへ違和感なく投入できる
- 靴なし、靴下のみでも足元が成立する
- 中程度の背景情報でも人物が埋もれない
- 小物に頼らず「あかりの朝」と分かる

## 5. 判断優先順位

制作判断が割れた場合は、次の順序を使う。

1. あかりに見えること
2. 脚と重心が自然であること
3. 生活中の姿に見えること
4. かわいく見えること
5. 絵として華やかであること

Core では「可愛いが不自然」より「地味だが自然」を選ぶ。

# 第2章：成果物と制作フロー

## 6. Core 成果物

### C01：自然姿勢・正面全身

v1.1 の正面基準と直接比較する中心アセット。

- 両足はほぼ平行
- 荷重は左右均等に近い
- 膝をロックしない
- 肩と肘にわずかな緩み
- 腰を反らせすぎない
- 健康的な脚の太さを維持
- 無地背景
- 通常髪、通常表情
- v1.1 の基本衣装

強い片足重心、首の傾き、モデル立ちは入れない。

### C02：自然姿勢・後ろ全身

- 頭頂、肩、腰、膝、靴底の高さを C01 と合わせる
- 後頭部のボブ形状を維持
- パーカー背面の膨らみを過剰にしない
- スカート丈と脚の太さを正面と一致させる
- 左右の靴を鏡像コピーにしない

### C03：自然姿勢・左右45度

髪飾り側と非髪飾り側を別々の画像として制作する。

- 髪飾りをキャラクター左側に固定
- 顔幅と頬の丸みを両方向で一致
- 胸郭、骨盤、脚の向きを同じ透視条件で扱う
- 片側だけ脚が細く見えない
- スカートとパーカーの重なりを自然にする

### C04：ぺたん座り基準

v1.2 Humanization の代表アセット。

**衣装は固定する。**

- 白いオーバーサイズパーカー
- グレーのプリーツスカート
- 白い二本ライン入り靴下
- スニーカーなし

**姿勢仕様**

- 無地に近いラグ上
- 両脚を前方から片側へ緩く流す
- 左右の膝位置を完全には揃えない
- 骨盤はわずかに後傾
- 背中は自然に丸まる
- 肩を落とす
- 足首とつま先は脱力
- 手は身体を支える最低限の配置

比較可能性を優先し、D01 の部屋着とは分ける。

### C05：起床直後の髪・眠気

- 頭頂部に小さな浮き
- 前髪の軽い割れ
- 襟足の部分的な外ハネ
- 頬へ落ちる毛束
- ボブ全体の輪郭は維持
- まぶたはやや重い
- 視線は完全には覚醒していない

C05 は literal な就寝直後の再現より identity 確認を優先するため、Core 基準では髪飾りを装着する。髪飾りなしの寝起き表現は Daily 派生として別途検討し、Core の必須要件には含めない。

### C06：日常笑顔グラデーション

各表情を一枚ずつ制作する。

- C06-1：ぼんやりした無表情
- C06-2：眠いが安心している
- C06-3：口元だけ少し緩む
- C06-4：柔らかく微笑む

変化対象：

- 上まぶたの開き
- 下まぶたの丸み
- 瞳の焦点
- 眉の高さと傾き
- 口角
- 頬の緩み

顔幅、顎、目の基本形は変えない。

### C07：室内足元基準

- 白地に淡いブルーの二本線
- 初期基準では左右同じ高さ
- 大きなたるみやずれを入れない
- 立位と座位を別々に検証
- 足首を過度に細くしない
- つま先をバレエのように伸ばさない
- 足裏の接地、浮き、圧縮を姿勢に合わせる

## 7. Daily 検証アセット

### D01：起床直後、ベッド脇のあかり

- ベッド脇の床またはラグ
- ぺたん座り
- 白いゆるい半袖Tシャツ
- グレー系の短パン型部屋着
- 白い二本ライン入り靴下
- 起床直後の軽い寝癖
- まだ眠い表情
- 柔らかな朝の自然光
- 中程度の背景情報
- 部屋は整いすぎず、散らかりすぎない
- 小物は必要最小限

D01 の目的は壁紙完成ではなく、Core 基準の実戦検証である。

## 8. 画像単位の制作ルール

すべての生成元画像は 1 ファイルにつき 1 構図とする。

- 正面、後ろ、左右45度を同時生成しない
- 表情差分を一枚に並べない
- 比較画像を直接生成しない
- 採用済み単独画像を後工程で資料化する
- 左右反転で別方向を代用しない

## 9. 制作フェーズ

### Phase 1：直立基準

対象：

- C01
- C02
- C03 髪飾り側
- C03 非髪飾り側

#### Gate 1：Identity Review

- v1.1 と同じ人物に見える
- 顔が大人化または幼児化していない
- 頭身が変わっていない
- 脚が細くなっていない
- 髪飾り側が正しい
- 配色が漂流していない
- 4方向で肩、腰、膝の位置が整合する

### Phase 2：座り・足元

対象：

- C04
- C07 立位
- C07 座位

#### Gate 2：Body Review

確認順：

1. 骨盤
2. 大腿部
3. 膝
4. すね
5. 足首
6. 足先
7. 上半身との重心整合

Gate 2 通過を Core 60% 完成と定義する。

### Phase 3：朝の状態差分

対象：

- C05
- C06-1〜4

#### Gate 3：State Review

- 寝癖が通常髪へ戻せる範囲
- 別髪型に見えない
- 髪飾り側が維持
- 4表情が連続的
- 眠気を目の細さだけで表現していない
- 表情差で顔骨格が変わっていない

### Phase 4：Daily 実戦検証

対象：

- D01

#### Gate 4：Daily Review

最優先評価は脚と重心の自然さ。背景、照明、小物、衣装の可愛さは二次評価とする。

問題がある場合は D01 だけを直さず、原因に応じて C04、C05、C06、C07 へ戻る。

# 第3章：造形ロック・生成仕様・版管理

## 10. 造形ロック

### 顔

- 丸みのある輪郭
- やさしく丸い目
- 暖色ブラウンの瞳
- 小さく控えめな鼻
- 柔らかい頬
- 小さめの口
- 25歳だが過度に大人びすぎない

### 髪

- 暖色寄りの茶髪
- 短いボブ
- 顎から首周辺の長さ
- キャラクター左側の平行ピンと小リボン
- 丸みのある後頭部
- 前髪の基本分けと密度

### 身体

- コンパクトなアニメ等身
- 小柄な印象
- 健康的でしっかりした脚
- 十分な太もものボリューム
- 柔らかなふくらはぎ
- 足首のみを極端に細くしない
- 小さめの手
- 狭めだが不自然に華奢ではない肩幅

### 基本配色

v1.1 の D65 / sRGB パレットを継承する。

- hair: `#6B4A37`
- skin: `#F4CBBE`
- eyes: `#7B5742`
- hoodie_white: `#F5F4EE`
- hoodie_shadow: `#D9DBD8`
- skirt_gray: `#74777D`
- sock_white: `#F7F8F4`
- sock_stripe_blue: `#9BD8E5`
- sneaker_white: `#F4F5EF`
- sneaker_accent_blue: `#A4DDE8`
- bag_body: `#F1EEE4`
- bag_strap: `#B5A997`
- metal: `#B7B8B3`

照明による見え方の変化は許容するが、物体固有色は変更しない。

## 11. 許容変化と禁止事項

### 許容

- 肩の高さの微差
- 骨盤の傾き
- 膝と足先の向き
- 左右の荷重差
- 座った際の服のしわ
- 寝癖による一部の毛束変化
- 眠気によるまぶた、眉、視線の変化
- 室内時の靴なし状態
- 朝光による柔らかな色温度変化
- 呼吸や脱力を感じる軽い非対称

### 禁止

- 頭身の変更
- 顔の縦長化
- 目の大幅な縮小
- 脚の細身化
- 髪の長さ変更
- 髪飾りの左右反転
- 靴下ラインの本数変更
- スカート丈の恒常的変更
- 基本色の別色化
- 写実的な人体比率への移行
- 別作品風に見える画風変更

## 12. 自然姿勢の許容範囲

### 正面立位

- 頭部の傾き：ごく小さく
- 肩の左右差：軽微
- 骨盤：ほぼ水平
- 荷重差：最大 55:45 程度
- 膝：完全伸展を避ける
- 足先：正面からわずかに外向き

### ぺたん座り

- 骨盤の軽い後傾
- 背中の自然な丸み
- 左右の膝位置の軽い差
- 両脚を片側へ緩く流す
- 足先の角度差
- 片手による軽い支持

両膝の強い内旋、無理な足首屈曲、脚を身体の下へ完全に巻き込む姿勢は禁止する。

## 13. 描画・レンダリング仕様

### 人物

- 柔らかなアニメ調
- 淡い陰影
- 強すぎない輪郭線
- 写実化しすぎない肌
- 頬、膝、指先にごく弱い血色
- 荷重と接触に沿った布しわ
- 大きな髪の塊と少数の毛束

### 背景

- 人物より少し現実的な空間構造
- 自然な家具寸法と透視
- 生活文脈を示す程度の小物
- 写真級の精密さは不要
- ボケで情報を消しすぎない
- 人物より高いコントラストにしない

### 光

- D65 基準色を壊さない
- 朝は柔らかい自然光
- 強い逆光や派手な光芒を避ける
- 顔と脚の形を読める
- 室内影を黒く潰さない

## 14. 共通生成仕様

すべての生成プロンプトに以下を含める。

> single standalone image, one scene only, one composition only, no collage, no grid, no split screen, no multi-panel, no contact sheet.

常時明示する要素：

- Akari v1.1 identity preserved
- 25 years old
- short warm-brown bob hair
- hair accessories on the character-left side
- warm brown eyes
- compact anime proportions
- sturdy healthy legs with fuller thighs and soft calves
- soft anime rendering
- natural joints and weight balance
- no logos, no text, no watermark

避ける傾向：

- overly thin legs
- elongated body proportions
- fashion model pose
- stiff mannequin posture
- hyperextended knees
- twisted ankles
- disconnected limbs
- mirrored hair accessories
- long hair
- adult glamorous face
- toddler-like proportions
- exaggerated breasts
- high heels
- bare feet when socks are specified
- mismatched sock height
- logos or brand marks
- dramatic cinematic lighting
- photorealistic skin
- cluttered background
- excessive accessories

## 15. ファイル命名規則

ファイル名は小文字で統一する。Asset ID はメタデータ上では大文字、ファイル名では小文字とする。

```text
akari-v1.2_<asset-id-lowercase>_<descriptor>_rNN.png
```

例：

```text
akari-v1.2_c01_front-natural-stance_r01.png
akari-v1.2_c02_back-natural-stance_r01.png
akari-v1.2_c03_hairpin-side-45_r01.png
akari-v1.2_c03_non-hairpin-side-45_r01.png
akari-v1.2_c04_floor-sitting_r01.png
akari-v1.2_c05_morning-bedhair_r01.png
akari-v1.2_c06-1_sleepy-neutral_r01.png
akari-v1.2_c07_indoor-socks-seated_r01.png
akari-v1.2_d01_morning-bedside_r01.png
```

## 16. 採用状態

- `candidate`
- `review`
- `accepted`
- `accepted-with-notes`
- `rejected`
- `superseded`

Rejected と superseded は削除せず、判断履歴として保存する。

## 17. レビューメモ

```yaml
asset_id: C04
revision: r03
status: review
identity:
  face: pass
  hair: pass
  hairpin_side: pass
body:
  proportion: pass
  leg_volume: pass
  weight_balance: needs_fix
state:
  expression: pass
  clothing: pass
notes:
  - character-right ankle is rotated too far inward
  - pelvis contact with floor is unclear
```

一度の改訂では、主な変更対象を一系統に限定する。

# 第4章：レビューシートと受け入れ基準

## 18. レビュー順序

1. Identity
2. Body
3. State
4. Rendering
5. Production

前段階に重大な問題がある場合、後段階は評価しない。

## 19. 重大度

### Blocker

- 別人に見える
- 髪飾りが反対側
- 頭身が変わっている
- 脚が明確に細い
- 関節や足が破綻
- 指定衣装や靴下が別デザイン
- 余分な手足
- 明確な色漂流

Blocker が一件でもあれば rejected。

### Major

- 方向間で肩や膝の高さが合わない
- 座り姿の荷重位置が曖昧
- 寝癖が別髪型に見える
- 表情差で顔輪郭が変わる
- 靴下の高さやライン位置が不安定
- 45度だけ脚の太さが変わる

原則修正。使用範囲を限定できる場合のみ accepted-with-notes。

### Minor

- 毛束一本の方向
- 小さな布しわ
- 背景小物の位置
- 軽微な色温度差
- 接地影の弱さ

## 20. 共通チェックリスト

### Identity

- [ ] v1.1 と同じあかりに見える
- [ ] 25歳の年齢感を維持
- [ ] 顔が縦長化していない
- [ ] 目の基本サイズと形が維持
- [ ] 暖色ブラウンの瞳
- [ ] 短いボブの輪郭を維持
- [ ] 髪飾りがキャラクター左側
- [ ] 配色が漂流していない

### Body

- [ ] 頭身が v1.1 と同程度
- [ ] 太ももの健康的なボリュームを維持
- [ ] ふくらはぎが細すぎない
- [ ] 足首だけが不自然に細くない
- [ ] 肩、骨盤、膝、足首の向きが整合
- [ ] 左右の脚の長さと太さが一致
- [ ] 荷重位置を説明できる
- [ ] 関節を衣服で誤魔化していない

### State

- [ ] 表情が身体状態と一致
- [ ] 脱力が単なる猫背ではない
- [ ] 寝癖が生活変化として読める
- [ ] 靴なし状態が成立
- [ ] 服しわが接触と重力に従う

### Rendering

- [ ] 柔らかなアニメ調
- [ ] 肌が写実化しすぎない
- [ ] 背景が人物より強くない
- [ ] 影が黒く潰れていない
- [ ] 顔と脚が読み取れる
- [ ] ロゴ、文字、透かしがない

### Production

- [ ] 一枚につき一構図
- [ ] ミラーを別角度として不使用
- [ ] ファイル名が規則準拠
