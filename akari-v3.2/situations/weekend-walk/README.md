# Akari v3.2 — 休日の街歩き

ユーザーが選んだ「雑貨店 → 風のある並木道 → 夕方の帰り道」を3枚にしました。
v3.2の基準セットをコミットした後、同じ顔と水色コーデから各場面を独立して生成しています。

## 3枚の流れ

| 場面 | 原寸画像 | 内容 |
| --- | --- | --- |
| C02 | [雑貨店で、小さな星を見つけた](images/C02-little-star-shop.png) | 星のキーホルダーを手のひらで見せる、近めの構図 |
| C03 | [並木道、風がふわっと](images/C03-breezy-tree-walk.png) | 買い物袋を持ち、風に髪を押さえて笑う全身 |
| C04 | [夕方の帰り道、もう少しだけ](images/C04-sunset-homeward.png) | 先を歩いて振り返り、そっと手招きする |

各画像は1024×1536の原寸PNGです。
白い小さな紙袋と水色の持ち手を共通の小道具にしています。
星のキーホルダーはC02で見つけ、C03/C04ではしまっています。

## 基準と生成記録

基準セットのコミット：`f0d13ba04e314b199ac84e631463889a6599efe6`。

- [B2](../../references/B2-pop-face.png)：顔、目、髪、細ピン、線と塗り。
- [G1](../../references/G1-soda-pop-full-body.png)：体型、水色コーデ、靴。
- [F09](../../../akari-v3.1/references/materials/F09-rounded-wrinkled-sock-detail.png)：見える靴下の柔らかい不透明な布と浅いしわだけ。
- [C02のプロンプト](prompts/C02-little-star-shop.txt)・[C03のプロンプト](prompts/C03-breezy-tree-walk.txt)・[C04のプロンプト](prompts/C04-sunset-homeward.txt)。
- [入力、保存先、SHA-256](manifest.json)。各場面の目視所見は `records/` に記録。

内蔵 `image_gen` で1場面ずつ、計3枚を生成しました。
生成元を残して作業フォルダーにコピーし、PNG読み込み、原寸、ハッシュ、コピー一致を確認しています。
場面間で顔を連鎖参照せず、すべて同じB2/G1/F09を入力しています。

## 確認したこと

顔、ボブ、ピン、衣装、手と小道具、歩行や振り返りのつながりを目視しました。
C03/C04の背景は基準ポートレートより描き込みがありますが、アニメイラストの表現です。
C04は指定したすね付近の切り方より下まで写り、下端にスニーカーの一部が入っています。
