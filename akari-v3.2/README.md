## 描き方

- やわらかい顔の輪郭、親しみやすいグレーのたれ目、普段は小さな閉じ口の微笑み。
- 瞳は上側と下側の明暗、小さな濃い楕円の瞳孔、丸い淡色反射で整理する。
- 黒髪ボブは大きな毛束と控えめなハイライトでまとめる。
- 明るい色面、浅いセル塗り、軽い頬色を使い、背景にも同じポップさを通す。
- 一本の細いシルバー直線ピンを本人の左側、耳の少し上に置く。正面では画面右側。
- B2/G1の年齢感と身体のバランスを保つ。写実的な肌や布、強い光沢、3Dにはしない。

## ソーダ色のコーデ

- 白い丸襟と短いパフ袖のブラウス、襟と袖口の控えめなフリル。
- 水色と白のギンガムのジャンパースカート。幅のあるフリル付き肩ひも、共布のウエスト。
- ふんわりした膝上丈のスカートと、一段のギンガムの裾フリル。
- 襟元に小さなレモン色のリボン。
- 白い短いフリルソックス、白と水色のローカットスニーカー。

この衣装ではG1を優先します。別の衣装を作るときも、顔はB2から参照します。

## 生成時の使い分け

生成前に必要な原寸画像を `view_image` で開き、各入力の役割をプロンプトに明記します。

| 作業 | 入力と役割 |
| --- | --- |
| 新しい場面絵 | B2＝顔と描き方、G1＝体型と衣装。場面、ポーズ、画角、表情はその都度指定 |
| 靴下が見える場面 | 上記に[F09足元詳細](../akari-v3.1/references/materials/F09-rounded-wrinkled-sock-detail.png)を布の質感だけ追加 |
| ピンを詳しく合わせる | [S1](../akari-v3.1/references/S1-silver-slim-pin.png)を形と位置だけ追加 |
| 既存画像の修正 | 修正対象を先頭にし、構図・ポーズ・カメラはその画像を優先。B2/G1は各担当の特徴を補助 |

G1や場面絵の小さい顔を次の顔原本にせず、B2の原寸を毎回使います。
新しい場面同士を連鎖させず、同じB2/G1から独立して生成します。
C01の座り姿勢、頬杖、閉じ口の表情はほかの場面を拘束しません。

靴下の柔らかく不透明な布と、浅くまばらな自然なしわは継承します。
F09の灰色や丈は移さず、このコーデでは白い短丈に合わせます。
靴が覆うつま先を見せる必要はありません。布越しに指、爪、指ごとの凹凸を描きません。
しわの位置は新しいポーズや接地に合わせます。

v3.1のP1/P2と原寸U1/L1は、B/G1に至る人物と身体の来歴です。
v3.2では選択済みB2/G1を優先し、旧版の細かい目の描写、制服、灰色の長い靴下へ戻しません。
機械可読の指定は[参照セット](reference-set.json)と[設計状態](design-state.json)にあります。
