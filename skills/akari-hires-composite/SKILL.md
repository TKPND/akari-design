# あかりの高解像度・分割合成

共通の全体原画から、顔や手を十分な画素数で描き直す領域を作り、重なりで合成する。
最終キャンバスの寸法と、生成原画が持つ細部の密度を分けて扱う。
通常拡大との比較を添え、改善と描き直しによる変化を両方伝える。

## 進め方

1. 既出の用途・版・枚数・構図を引き継ぐ。
   横長4K壁紙は3840×2160、縦長9:16壁紙は2160×3840。
   「ポートレート」は顔寄り・上半身などの画角と、縦横比を別々に決める。
   1枚の試作を頼まれたら1枚で検証し、既に許可された工程を再確認で止めない。
2. 対象版のREADME、design-state.json、reference-set.jsonと原寸参照画像を確認する。
   [生成と参照](references/generation.md)に従い、最新アルバム評価も参照する。
   V4.0はV11が顔と描き方、B06が体格。衣装や構図は依頼に合わせる。
3. 全体原画を作成・確認して配置を固定する。既存絵の修正ならその絵が構図・ポーズ・カメラを持つ。
   同じ全体原画からすべての領域ガイドを切り出す。
   顔・銀ピン・手・関節を境界で分断せず、つながった人体を一つの領域に収める。
   領域の個数と座標は実際の絵から決める。
4. 各領域を独立して生成し、原寸PNG・プロンプト・入力順・役割・成否を保存する。
   出力寸法を実測し、配置倍率 `max(領域幅/原寸幅, 領域高さ/原寸高さ)` を記録する。
   小さい顔を含む全体原画の拡大より、顔領域の配置倍率を小さくする。
5. [合成と検証](references/assembly.md)のJSONと補助スクリプトを使う。
   縦横比を保って配置し、静かな背景や布面の重なりで接続する。
   目視でマスクを決め、二重線があれば接合位置または領域を見直す。
6. 全体表示と同一座標の等倍切り出しで、顔・手・衣装・靴下・接合部を確認する。
   PNGの全デコード、寸法、ハッシュ、比較画像の座標も確認する。
   PNG、比較、原画、生成記録を渡し、採用・commit・公開は依頼の範囲に従う。

## よくある失敗

| 状況 | 対処 |
| --- | --- |
| 横長の固定6分割を縦長へ流用する | 顔と体の配置から領域を組み直す |
| 境界の袖・手が二重になる | その輪郭を一つの原画に持たせ、接合を移す |
| 合成後に全体を再生成して解像度が落ちる | 完成サイズの組み立ては決定的な画像処理で行う |
| 出なかった領域を成功扱いにする | 成否と合成対象を分け、不足領域・通常拡大が残る範囲を記録する |
| 4Kという寸法だけで画質向上を断言する | 原寸・配置倍率・等倍比較で説明する |

## 検証済みの範囲

2026-09-24の横長1枚では、全体1672×941から6領域を合成し3840×2160を作成。
顔領域の配置倍率は約1.126、全体の通常拡大は約2.297だった。
比較対象はLanczos拡大。学習型アップスケーラー全般への優位性は未検証。
縦長の座標処理・合成は自動テスト対象だが、縦長ポートレートの新規生成品質は未検証。
